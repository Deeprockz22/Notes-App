## 🍏 1. Apple Notes Full Parity Suite

* 📁 **Hierarchical Folders**: *All Notes, Quick Notes, Work, Personal, Ideas & Drafts, Archive, and Recently Deleted (Trash Bin)* + Custom folder creation.
* 🎨 **Whiteboard Drawing Canvas**: Embedded drawing pad with pen, highlighter, eraser, brush thickness sliders, and instant note embedding.
* 🔒 **4-Digit Biometric PIN Lock**: Password-protect sensitive notes with blurred previews and animated numeric security keypad.
* 📊 **Dynamic Tables & Rich Markdown**: Add interactive data tables, checkboxes, quotes, code snippets, and headers.
* 🏷️ **Smart #Hashtags & Live Analytics**: Real-time word count, character count, reading time calculator, and hashtag pills.
* 📥 **Export to Markdown**: 1-click export of any note into portable `.md` format.

## 🧠 4. Cognitive Science & Memory Offloading

> *"Your brain is a processor, not a hard drive. It is built for **having** ideas, not holding them."*

Holding unwritten tasks consumes up to **40% of working memory bandwidth** (*Miller's Law & Sweller's Cognitive Load Theory*). **FOCUS** actively prompts and reminds you to offload fleeting sparks onto notes and task queues, freeing your subconscious for creative problem solving.

## 🛠️ Tech Stack & Architecture

- **Core**: React 19, Vite 6, Modern ES Modules
- **Animations**: Framer Motion 12, Canvas Confetti
- **Component Design System**: Curated [React Bits](https://github.com/DavidHDev/react-bits.git) (`ShinyText`, `BlurText`, `SpotlightCard`, `DecryptedText`, `MagnetButton`, `ParticlesBackground`, `ClickSpark`)
- **Audio Engine**: Native Web Audio API procedural synthesis (binaural beats, white noise, chiptune coins, laser zaps)
- **Deployment**: Automated GitHub Actions CI/CD to GitHub Pages

## 🚀 Quickstart & Local Setup

```bash
# 1. Clone the repository
git clone https://github.com/Deeprockz22/Notes-App.git

# 2. Navigate to project directory
cd Notes-App

# 3. Install dependencies
npm install

# 4. Launch development server
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser!

### 📦 Build & Deploy to GitHub Pages:
```bash
npm run deploy
```
